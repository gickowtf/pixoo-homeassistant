## What's new

- Added an API endpoint fallback for Pixoo firmware that uses port 9000 (#151).
- Added BDF font support, bundled pixel fonts, Unicode glyphs, and custom fonts from Home Assistant's font folders (#154).
- Fixed font fallback consistency, handling of malformed custom fonts, and a missing pixel in the five_pix font.
- Improved regression tests and added automated Python tests alongside HACS and Hassfest validation.

## Upgrade notes

Text components now preserve lowercase letters. PICO_8 displays lowercase as small caps, and five_pix uses its lowercase glyphs. To keep the previous all-uppercase appearance, use uppercase text or the Jinja `upper` filter.

Component animations and hosted GIF playback (#157 and #158) are not included in this release.

## Validation

18 tests and five font subtests passed with Python 3.12, Home Assistant 2024.3.0, and Pillow 10.2.0. HACS and Hassfest validation passed for the integrated changes. No physical-device test was performed during this review.

Thanks to @mfishma for BDF font support.
